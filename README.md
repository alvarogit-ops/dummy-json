# Projeto 01 - Catálogo de Produtos (DummyJSON)

Aplicação web desenvolvida de Programação Orientada a Serviços, do curso de Informática (2026), utilizando **Vite** e consumindo dados de produtos em tempo real da API pública **DummyJSON**. O sistema permite selecionar diferentes categorias de produtos e exibe os itens correspondentes com imagem, título e preço.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** & **CSS3** (com variáveis customizadas, responsividade e suporte a tema escuro/claro)
* **JavaScript (ES6+ Modules)** (para manipulação do DOM e consumo assíncrono de APIs)
* **Vite** (como ferramenta de build e servidor de desenvolvimento)
* **DummyJSON API** (fonte de dados dos produtos)

## 🚀 Como Executar o Projeto

Certifique-se de ter o **Node.js** instalado em sua máquina.

1. Clone o repositório ou navegue até a pasta do projeto:
```bash
cd alvarogit-ops-pos-2026-projeto01

```


2. Instale as dependências:
```bash
npm install

```


3. Inicie o servidor de desenvolvimento:
```bash
npm run dev

```


4. Abra o link gerado no terminal (geralmente `http://localhost:5173`) no seu navegador.
